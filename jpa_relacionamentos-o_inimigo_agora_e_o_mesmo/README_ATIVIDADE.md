# Atividade concluída

Endpoints principais:

## Pessoa / Documento
- `POST /pessoa`
- `GET /pessoa/{id}`

## Funcionário / Endereço
- `POST /funcionario`
- `GET /funcionario/{id}`

## Aluno / Curso
- `POST /aluno`
- `POST /curso`
- `POST /aluno/{alunoId}/curso/{cursoId}`
- `GET /aluno/{id}`
- `GET /curso/{id}`

## Música / Playlist
- `POST /musica`
- `POST /playlist`
- `POST /playlist/{playlistId}/musica/{musicaId}`
- `GET /playlist/{id}`

## Livro / Usuário / Contato
- `POST /livro`
- `POST /usuario`
- `POST /usuario/{usuarioId}/livro/{livroId}`
- `GET /usuario/{id}`
